# Assumptions

1. There is one queen in each hive and she lays the same number of eggs every day. This simplifies the calculation.
2. Bees in the same group have the same probability of surviving and moving to the next group because they are at the same stage.
3. Food is sufficient. We do not consider food shortage because there is a field near the hive.
4. The weather is the same for all hives, so the same parameters can be used.
5. Each flower needs one visit. This makes the pollination model easier to calculate.
6. Disease and other factors are ignored.
