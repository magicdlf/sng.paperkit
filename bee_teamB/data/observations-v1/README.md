# 蜂群实测数据

原始文件 raw/pop.csv 已取得，SHA256与Dryad版本416183一致。observations.csv仅规范列名与日期，未拟合、插值或填补缺测，保留原始小数估计。quality.json记录范围和总量核查。数据源：https://datadryad.org/dataset/doi:10.5061/dryad.5tb2rbpg5 。

注意：实际CSV包含185行、9个蜂群，日期超出来源页面所述夏季研究窗口。拟合前按蜂群和日期选择样本，不能把全表直接称为夏季数据。Adults未区分巢内蜂与采集蜂；不要将原Total当成成蜂数量。原始文件仍保留在workshop/data。
