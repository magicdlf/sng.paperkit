# Problem Restatement

Honeybees are important for agriculture and their population changes with time. Therefore, we need to build a mathematical model to study the population of honeybees. We should consider the factors that affect the population and analyze their effects. Finally, we need to calculate the number of hives required for a 20-acre field. Our model should be reasonable and useful in real life.

We divide the problem into population prediction, weather analysis and pollination calculation. By solving these three parts, we can give suggestions for protecting bees and improving agricultural production.
