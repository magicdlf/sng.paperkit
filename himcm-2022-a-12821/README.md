# HiMCM 2022 A — Team 12821 import trial

Source: local archive PDF 12821.pdf, “Shedding Light on the Population of the Honeybee”. This is a transcription for classroom and layout evaluation, not an original PaperKit paper. Original authorship remains with Team 12821.

## Import scope and known differences

- Summary, body chapters, references and nontechnical infographic imported. Original TOC is regenerated by PaperBuilder.
- Main displayed equations reconstructed as editable LaTeX. Inline formula extraction is approximate and needs proofreading against the source.
- Graphs/flowchart/infographic retained as high-resolution source crops. Original Figure 12 spans four panels across pages; imported as two image groups, so generated figure numbering differs after that point.
- Table 2 is preserved as two source-image groups; other seven tables are editable (wording shortened for variable definitions). Image table groups affect figure numbering. Most explicit source figure/table/equation references are mapped to labels; implicit numbers and grouped panels still need proofreading.
- References preserve extracted wording, including incomplete original entries; metadata is not independently verified.
- No AI Use Report added: the 2022 source has none. No claim of matching original pagination.
- The current official layout is used unchanged. Differences due to extraction/images must be separated from template typography.
- This trial is prepared locally. No remote publication is performed by this import.

Open this folder with --paper. Build output is ignored by Git. Original PDF is kept in the local archive, not copied into the repository.

### 导入误差与后续校对

- 正文保留原文论述，不保证科学结论正确；行内上下标和分式存在提取残片，需要逐段校对。
- 表 2 被保留为图片，原图 12 的跨页组合被拆为两组；本地编号因此与原稿不同。不能将这些编号变化当成模板错误。
- 页间段落有部分额外断开；参考文献还未完整结构化。未用不存在的数据补写原稿。
- 本次可用作样式诊断与功能试验，尚不适合作为忠实校订版分发。

建议下一步先比较 Summary Sheet、目录和纯文字引言，再单独测试 native 表格及图的浮动位置。调整时保留当前 official 预设，新增可配置项或新预设，避免将某队的历史排版直接当成比赛规范。
