# LaTeX 手打练习

这一页练习自己输入公式，不需要安装 TeX Live。公式预览在浏览器内完成，PDF 编译才需要额外的 TeX 环境。

## 第一种方式：公式输入框

点击工具栏 ƒ 插入行内公式，或点击 ∑ 插入独立公式。在弹出的输入框里键入下面内容，不要加美元符号：

```text
\frac{x}{y}
```

观察预览，再点击保存，或按 Ctrl+Enter（Windows）/ ⌘Enter（Mac）。点击已有公式可以重新编辑。

效果示例：$\frac{x}{y}$。试着把分子改为 x+1，分母改为 y^2。

## 第二种方式：直接在正文里键入

在普通正文段落里，逐字键入下面这一整串，包括开头和结尾各两个美元符号；最后一个美元符号输入后会触发转换：

```text
$$\frac{x}{y}$$
```

它是网页编辑器的行内公式快捷输入。不要在代码块里输入；整串粘贴未必触发键入规则，本练习请手打。

如果希望公式独占一行，新建一个空段落，在段落开头手打下面这一串，前后各三个美元符号：

```text
$$$\frac{x}{y}$$$
```

注意：网页快捷输入与磁盘 Markdown 语法目前不同。Markdown 文件使用单个美元符号包围行内公式，独立公式使用单独一行的两个美元符号包围多行内容。不要把文件语法直接套用到网页键入规则。

## 练习清单

在公式输入框中输入下列代码；也可以在正文中用前后两个美元符号包围它们，逐字键入。

| 练习 | 输入内容 |
| --- | --- |
| 分式 | `\frac{x+1}{y^2}` |
| 上下标 | `N_0 e^{-\lambda t}` |
| 根号 | `\sqrt{x^2+y^2}` |
| 希腊字母 | `\alpha+\beta=\lambda` |
| 求和 | `\sum_{i=1}^{n} x_i` |
| 带括号分式 | `\left(\frac{x}{y}\right)^2` |

对照效果：$\frac{x+1}{y^2}$，$N_0 e^{-\lambda t}$，$\sqrt{x^2+y^2}$，$\alpha+\beta=\lambda$，$\sum_{i=1}^{n} x_i$。

反斜杠表示命令；花括号把多个字符组成一组。比较 x^12 和 x^{12}，以及 N_10 和 N_{10}，观察少写花括号会发生什么。

## 独立公式与编号

用 ∑ 按钮插入公式，把下面内容输入公式框：

```text
N(t)=N_0 e^{-\lambda t}
```

在标号框中填入 eq:practice-decay，它会获得编号。然后使用交叉引用工具在正文引用这个公式。留空标号时不编号；不要手写编号。

多行推导在独立公式输入框中使用 aligned：

```text
\begin{aligned}
N(t)&=N_0 e^{-\lambda t}\\
N(0)&=N_0
\end{aligned}
```

这里 & 是对齐位置，两个连续反斜杠表示换行。不要把 aligned 改成 align；多行内容请用公式输入框，不用单行快捷键入。

## 检查自己是否完成

1. 手打一个分式，看到真正的上下分式，而不是普通反斜杠文字。
2. 点击公式修改分母，保存后预览随之改变。
3. 给独立公式添加标号，并插入交叉引用。
4. 等待保存成功，再刷新页面，确认公式仍存在。

遇到预览报错，先检查反斜杠、成对花括号和命令拼写。浏览器使用 KaTeX，不能把完整 LaTeX 文档或任意宏包命令放进公式框；不认识的命令先改成 KaTeX/LaTeX 共同支持的写法。
